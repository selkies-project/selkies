# PixelFlux 2.2.4

## Build & CI

- **CPython 3.11 stable-ABI wheels** : each Linux platform now carries one `cp311-abi3` wheel for GIL-enabled CPython 3.11 and newer instead of a wheel per interpreter. The native frame buffer protocol requires the 3.11 limited API; free-threaded interpreters are not supported. This does not stabilize the Rust, codec, CUDA/NVENC, libc, OS, or CPU-architecture interfaces, so `manylinux_2_28`/`musllinux_1_2` and x86_64/aarch64 wheels remain separate
