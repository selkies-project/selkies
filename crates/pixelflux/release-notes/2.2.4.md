# PixelFlux 2.2.4

## Build & CI

- **CPython 3.11 stable-ABI wheels** : each Linux platform now carries one `cp311-abi3` wheel for GIL-enabled CPython 3.11 and newer instead of a wheel per interpreter. The native frame buffer protocol requires the 3.11 limited API; free-threaded interpreters are not supported. Ordinary source builds retain the full CPython API on 3.9 and newer, while releases continue to publish wheels only; an older interpreter therefore builds from a source tree rather than using the cp311-abi3 wheel. This does not stabilize the Rust, codec, CUDA/NVENC, libc, OS, or CPU-architecture interfaces, so `manylinux_2_28`/`musllinux_1_2` and x86_64/aarch64 wheels remain separate
