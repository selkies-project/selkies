# pcmflux 2.2.1

A maintenance release for Selkies 2.2.0, which pins it beside pixelflux 2.2.2: the library behaves as 2.2.0 did, built on its updated dependencies.

## Build & CI

- **PyO3 0.30** (from 0.29) and **opusic-sys 0.7.6** (from 0.7.5), with libc 0.2.191
- Releases are cut the way the other selkies-project repositories cut theirs: from the Actions tab with the tag, or by pushing it
- cibuildwheel and the GitHub Actions updated
